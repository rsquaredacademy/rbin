## Decisions made

- A one-column matrix is converted with `as.vector()` in the shared prep step,
  so every fitting method and `rbin_factor()` get the same treatment; the same
  helper is used at the start of `rbin_create()` scoring. Matrices with more
  than one column stop with a message naming the predictor.
- Missing addin dependencies now always stop with a clear message; the old
  interactive install prompt was removed rather than kept for interactive
  sessions, because the requirement is to stop regardless of `interactive()`.
  This also made `menu()` and `install.packages()` imports unnecessary.
- Blank cut-point boxes are removed as missing values before the existing
  length check, which preserves the existing validation text exactly.
