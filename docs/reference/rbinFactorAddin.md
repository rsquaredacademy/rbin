# `Custom binning`

Source:
[`R/rbin-addins.R`](https://github.com/rsquaredacademy/rbin/blob/HEAD/R/rbin-addins.R)

`rbinFactorAddin.Rd`

Manually combine categorical variables using weight of evidence.

## Usage

``` r
rbinFactorAddin(data = NULL)
```

## Arguments

- data:

  A `data.frame` or `tibble`, or the name of one. When `NULL` (the
  default), the current editor selection is used as the initial data
  name.

## Examples

``` r
if (FALSE) { # \dontrun{
rbinFactorAddin(data = mbank)
} # }
```
