# Bin continuous data

Manually bin continuous data using weight of evidence.

## Usage

``` r
rbinAddin(data = NULL)
```

## Arguments

- data:

  A `data.frame` or `tibble`, or the name of one. When `NULL` (the
  default), the current editor selection is used as the initial data
  name.

## Examples

``` r
if (FALSE) { # \dontrun{
rbinAddin(data = mbank)
} # }
```
